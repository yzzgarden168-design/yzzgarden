## 🚀 快速开始

### 安装要求
- 现代浏览器（Chrome、Firefox、Edge、Safari）
- 无需安装任何依赖
- 支持本地运行

### 使用步骤

1. **打开系统**
   - 双击 `index.html` 文件
   - 或在浏览器中打开该文件

2. **导航菜单**
   - 📊 仪表盘：整体进度和核心指标
   - 📈 数据分析：详细数据图表
   - ✅ 任务管理：30天任务清单
   - 🔍 关键词追踪：关键词排名监控
   - 📝 内容管理：内容发布记录
   - 📅 日历视图：执行计划日历
   - ⚙️ 设置：系统配置

3. **数据刷新**
   - 点击右上角"🔄 刷新数据"按钮
   - 系统每5分钟自动刷新一次

## 📊 核心指标说明

### 进度指标
- **总体进度：** 整体项目完成百分比
- **任务完成率：** 已完成任务/总任务
- **关键词排名：** 平均关键词排名
- **内容输出：** 已发布内容数量

### 效果指标
- **曝光量：** 累计品牌曝光次数
- **自然流量：** 自然搜索访问量
- **转化率：** 访问转化的百分比
- **平均排名：** 核心关键词平均排名

### 投资回报
- **总投入：** 项目累计投入金额（元）
- **预期回报：** 预计总回报金额（元）
- **当前回报：** 已实现回报金额（元）
- **ROI：** 投资回报率百分比

## 🔧 数据配置

### 修改项目信息
编辑 `data.js` 中的 `systemState` 对象：

```javascript
const systemState = {
    startDate: '2026-04-03',  // 开始日期
    endDate: '2026-05-02',    // 结束日期
    totalDays: 30,            // 总天数
    currentDay: 14,           // 当前天数
    overallProgress: 35,      // 总体进度百分比
    // ... 其他配置
};
```

### 修改任务数据
编辑 `data.js` 中的 `executionPlan` 对象：

```javascript
const executionPlan = {
    phases: [...],  // 阶段信息
    tasks: [...]    // 任务列表
};
```
