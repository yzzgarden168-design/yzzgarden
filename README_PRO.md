# 园之助 AIGEO智能监控系统 Pro

> 2026-08 可执行版：系统已升级为真实联网扫描与持续监控工作台，原模拟数据模块仍保留为历史参考。

## 当前版本快速启动

双击 `启动系统Pro.bat`。程序会启动本地服务并打开 `http://127.0.0.1:8765`。

首次使用建议：

1. 在“策略设置”填写品牌和重点实体/关键词；
2. 在“联网体检”输入自己有权检测的公开网页；
3. 查看评分与自动生成的改进任务；
4. 完成页面修改后再次扫描，在“监控历史”验证得分变化。

### 自动生成内容

进入“生成新内容”，选择平台并填写产品、关键词、卖点、受众和语气。系统会自动生成、保存并提供复制与发布状态管理。默认使用内置规则模板，无需额外配置。

如需启用 AI 生成，可在启动前设置以下环境变量：

- `AIGEO_AI_API_KEY`：服务端 API 密钥（也兼容 `OPENAI_API_KEY`）
- `AIGEO_AI_MODEL`：模型名称，默认 `gpt-5-mini`
- `AIGEO_AI_BASE_URL`：兼容 Responses API 的服务地址，默认 `https://api.openai.com/v1`

密钥只由本地 Python 服务读取，不会发送到浏览器。AI 接口临时不可用时，系统会自动回退到规则生成。

运行要求：Windows 与 Python 3.10+。运行数据保存在 `runtime_data/monitoring.json`，无需数据库或额外依赖。系统默认只监听本机，并拒绝访问本机、内网和超大页面。

## 📊 数据说明

### 内容质量评分
- **关键词密度**（权重20%）：关键词出现的频率和分布
- **内容长度**（权重15%）：内容长度是否适合平台
- **可读性**（权重15%）：内容是否易于阅读
- **情感吸引力**（权重15%）：是否能引起读者共鸣
- **平台适配性**（权重20%）：是否符合平台特性
- **独特性**（权重15%）：内容是否原创独特

### 平台效果评分
- 发布数量 × 1
- 平均浏览量 × 0.1
- 平均互动量 × 0.01
- 平均互动率 × 2
- 转化率 × 10
- 收入 × 0.01

### ROI计算公式
```
ROI = (总收入 - 总成本) / 总成本 × 100%
```

## 🐛 故障排除

### 问题1：图表不显示
**解决**：确保网络连接正常，Chart.js CDN可访问

### 问题2：数据丢失
**解决**：定期导出数据备份，清理浏览器缓存可能导致数据丢失

### 问题3：页面加载缓慢
**解决**：减少历史数据量，或使用时间范围筛选

### 问题4：内容生成失败
**解决**：检查输入参数是否完整，刷新页面重试
